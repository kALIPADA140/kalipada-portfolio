# Kalipada Maji — Portfolio Website

## Files
- `index.html` — website content and SEO metadata
- `style.css` — dark modern responsive design
- `script.js` — mobile navigation and current year
- `favicon.svg` — browser tab icon
- `profile.jpg` — add your own profile photo (not included)

## Before publishing
1. Add your own portrait photo to this folder and name it `profile.jpg`.
2. In `index.html`, replace `YOUR-EMAIL@example.com` with your real email.
3. Replace the GitHub and LinkedIn links with your actual profile URLs.
4. Edit the sample project descriptions to match projects you have actually completed.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com/.
2. Create a new public repository named `kalipada-portfolio`.
3. Upload all files from this folder to the repository root (not the folder itself).
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub Pages to publish. Your URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/kalipada-portfolio/`

## Help Google discover the site
1. Open https://search.google.com/search-console/
2. Add your published URL using the **URL prefix** option and complete verification.
3. Use **URL Inspection** to inspect the homepage URL and select **Request Indexing**.
4. Make sure the site is public and the page is not blocked from indexing.
5. Search Google for your exact name and site URL after some time.

Google indexing is not instant and cannot be guaranteed. Use your real name consistently in the page title, main heading, description, and public profiles. Keep your site useful and updated.
